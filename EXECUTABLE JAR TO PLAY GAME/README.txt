Aero Fighter - Greenfoot Game

Requirement:
Java 8 is required.

Windows:
Double-click run-windows.bat

Linux/Mac:
Run:
java -jar MyFirstGame.jar

Note:
Double-clicking the JAR may not work if your system uses Java 17 or Java 21.
This Greenfoot game was exported using an older Greenfoot version and needs Java 8 JavaFX.
