Aero Fighter - Greenfoot Game

This game was developed in Greenfoot.

Recommended Greenfoot version:
Greenfoot 3.5.4

To edit or run the source project:
1. Install Greenfoot 3.5.4.
2. Open this project folder in Greenfoot.
3. Click Compile.
4. Click Reset.
5. Click Run.

To run the exported JAR on Windows:
Double-click run-windows.bat.

Important:
Do not use Java 17 directly for old Greenfoot JARs.
This game works best with Java 8.
